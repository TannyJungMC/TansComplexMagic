My source code maybe a bit different from others. I made it with IntelliJ and MCreator (currently using 2026.2), each serving different purposes. MCreator for game version switching and handling hard things such as custom blocks, items, and entities. IntelliJ for handcode. If it's hard to understand or bad design, I'm sorry. For who want to do something with my code, please read my agreements below.

- To run client or server.  In IntelliJ, go to "Gradle" tab at right side, select `Gradle > Tasks > mod development > runClient or runServer`. In MCreator, click the green buttons at top-right.
- To export the mod to JAR format. In IntelliJ, go to "Gradle" tab at right side, select `Gradle > Tasks > build > build`. The exported file will be in `Project Folder > build > libs`. In MCreator, click the orange button then choose path of exported file.
- In case you want to switch the code to different supported game versions. Download MCreator same version as I mentioned above. Install needed plugins, I already put them in the folder ".mcreator_plugins". Open MCreator, open workspace settings, switch version of the generator. After finish MCreator part, then go to IntelliJ to switch codes in handcode parts. Use find tool to find all text like this "(1.12.2)", it will show you all my change marks, switch the changes by copy and paste them to the code below.
